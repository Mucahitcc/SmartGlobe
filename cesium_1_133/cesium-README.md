# CesiumJS Kütüphanesi

Bu klasöre **CesiumJS 1.133** sürümü yerleştirilmelidir.

Kütüphane, dosya boyutu nedeniyle depoya dahil edilmemiştir.

## Kurulum

1. [cesium.com/downloads](https://cesium.com/downloads/) adresinden **CesiumJS 1.133** sürümünü indirin
2. Arşivi açın ve içeriğini bu klasöre kopyalayın

## Beklenen yapı

```
cesium_1_133/
└── Build/
    └── Cesium/
        ├── Cesium.js
        └── Widgets/
            └── widgets.css
```

`index.html` bu yolları referans alır; farklı bir sürüm kullanacaksanız
`index.html` içindeki script ve stil yollarını güncelleyin.
